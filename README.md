# Student Management System 

This is a simple command-line application built using Python to manage student records. It allows users to add, view, update, and delete student details, along with checking pass/fail status.

The data is stored using JSON, so records are saved even after the program is closed.

## Features
- Add, view, update, and delete student records
- Check pass/fail result
- Persistent storage using JSON

## How to Run
Make sure Python is installed, then run:

python student_manager.py
